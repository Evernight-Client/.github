Evernight

一个轻量、简洁、开源的 Minecraft 作弊客户端。

Evernight 是一个独立维护的 Minecraft 客户端项目，专注于稳定的模块系统、清晰的代码结构与良好的可扩展性。

特性

· 🧩 模块化设计，功能开关与配置一目了然

· 🎨 简洁的 ClickGUI，支持拖拽与自定义主题

· ⚡ 低性能开销，不影响游戏帧率

· 🔧 易于二次开发，提供清晰的 API 与注释
